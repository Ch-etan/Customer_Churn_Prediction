# Customer Churn Prediction

## Overview

Customer Churn Prediction System built using Machine Learning and Streamlit.

## Features

- Customer Churn Prediction
- Interactive Dashboard
- Plotly Charts
- Logistic Regression
- Random Forest
- Beautiful UI
- Business Recommendations

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Joblib

## Dataset

Telco Customer Churn Dataset

streamlit run app.py
